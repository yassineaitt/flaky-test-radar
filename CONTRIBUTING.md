# Contributing

## Setup

```bash
uv sync
uv run pre-commit install --hook-type pre-commit --hook-type commit-msg
```

## Local gate

```bash
uv run ruff check . && uv run ruff format --check . && uv run mypy
uv run pytest --cov                       # ≥ 85 % enforced
uv run flaky-radar render samples/results --out site && open site/index.html
```

`samples/` is generated by `scripts/make_samples.py` with a fixed seed; CI fails if the
committed files drift from the script.

## Commit messages

Conventional Commits (`feat`, `fix`, `test`, `ci`, `build`, `docs`, `chore`, `refactor`, `perf`),
checked by the `commit-msg` hook.

## Where things go

| Change                        | File                                     | Rule                                                        |
| ----------------------------- | ---------------------------------------- | ----------------------------------------------------------- |
| A new input format            | `parse.py`                               | Reduce to `TestResult`; add a fixture-based test            |
| Scoring / verdict logic       | `analyze.py`                             | Keep it explainable; update footer text + README            |
| Dashboard look                | `templates/dashboard.html.j2`            | No external assets; must work offline and in both themes    |
| CLI behaviour                 | `cli.py`                                 | Exit codes: 1 input error, 2 gate failed                    |
| Workflow inputs               | `.github/workflows/radar.yml`            | Backwards compatible defaults                               |
